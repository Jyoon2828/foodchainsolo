먹이사슬 술래잡기 개인 체험용 1.5.0
검사일: 2026-10-22

자동 검사 55개 통과
명령: node --test tests/*.test.mjs

그림 퀴즈
- 문제의 먹는 생물/먹이 슬롯과 보기를 실제 내장 그림으로 표시
- 문제/보기 마크업에 화살표 문자열 없음
- 틀리면 재도전하며 틀린 먹이관계를 정답 그림처럼 보여 주지 않음
- 정답을 고르면 그림 두 개와 먹기 표현을 표시하고 보기 잠금
- 정답 전 다음 역할로 이동 방지, 잘못된 ID/예전 보기 번호/배열 답 거부
- 정답 선택과 정리용 먹이사슬을 역할별 기록에 보관

먹이그물 숲 게임
- 참새/생쥐/뱀/매의 네 역할, 각 역할이 서로 다른 먹이 종류를 모두 찾는 미션
- 먹이 종류마다 충분한 수와 시작 위치 가까운 먹이 하나 이상 배치
- 대각선 이동속도 정규화, 가속과 방향 변화, 경계 유지
- 먹이표에 있는 관계만 먹기/잡힘 처리, 같은 먹이 종류 중복 집계 방지
- 잡혀도 찾은 먹이 보존, 2초 재출발과 재출발 후 3초 보호
- 빠르게 이동의 대기시간, 일시정지 시 시간/이동/대기시간 정지
- 자동 추격 입력으로 네 역할의 미션을 각각 90초 안에 완료
  (게임 자체에는 시간제한이 없으며 학생 플레이 시간을 실측한 결과가 아님)
- 네 역할을 마치며 기존 네 관계와 새 여섯 관계를 합쳐 10개 완성
- 실제 먹기/잡힘 이벤트에서만 새 관계를 기록하며 중복 관계 방지
- 네 역할을 마치기 전 관찰 단계로 건너뛰지 못함
- 별도의 활동 사이 기록 독립, 새 역할과 재시작 때 상태 초기화

먹이그물 정리
- 개구리 가리기는 직접 연결 두 개만 흐리게 하며 다른 생물을 자동 제거하지 않음
- 생쥐와 참새라는 두 대체 먹이를 모두 찾아야 생각 정리로 이동
- 그림에서 먹이사슬을 강조해도 관계 자료는 변하지 않음
- 모든 결과 화살표는 먹히는 생물에서 출발해 먹는 생물 카드 바깥에서 끝남
- 생각 글자 수 제한, 공백만 있는 기록 방지
- 내 생각 HTML 문자 이스케이프와 PNG 저장

기존 먹이사슬 게임과 오디오 회귀 검사
- 개인 시작/설정/네 역할/기록/다시 시작/점프/숨기/오프라인
- 60·90·120Hz 표시 조건의 위치 보간, 작은 방향 변화의 그림 깜빡임 방지
- 과도한 상하 들썩임 제한, 뱀 수직 튀기 없음, 실제 위치/미션 판정과 표시 분리
- 보통 설정에서 메뚜기 8/개구리 7/뱀 6마리 및 일부 먹이 가까운 출발
- 역할 변경/재시작 때 숲 친구 중복 누적 방지
- 컴퓨터 생물 완만한 방향 변경과 학생보다 느린 먹이 속도
- 사용자 동작 전 AudioContext/음악 예약 없음
- BGM/효과음 개별 끄기, 음량 0 처리, 단일 음악 예약 타이머 유지
- 동시 합성 음성 제한, 같은 효과음의 빠른 중복 방지
- 일시정지/창 비활성화/탭 이동에서 음과 예약 해제
- 오디오 API 없음/재개 거부에서도 게임 진행
- 내 캐릭터 행동음만 재생하고 미션 성공음은 역할별 1회

최종 index.html 전체 번들 통합 스모크 검사 통과
DOM 대역, 네이티브 캔버스, 내장 생물 그림을 이용해 전체 스크립트를 실행함.
- 시작/설정/이동/점프/멈춤/재개/도움말/소리 설정/다른 탭/창 비활성화
- 네 역할 그림 퀴즈의 오답/정답/다음 역할과 도움말 전후 선택 보존
- 정리 화면에서 먹이그물 진입, 직접 진입, 처음으로 이동 취소, 재시작
- 먹이그물 게임 이동/빠르게 이동/일시정지/도움말/소리 설정/그림 기록
- 배경 전환 후 명시적 재개, 네 미션 완료, 역할 전환 시 입력 리스너 누적 없음
- 개구리 가리기/두 먹이 찾기/생각 입력/PNG 저장/결과 재진입과 기록 유지
- 오디오 API가 없는 경우와 오디오 API 대역이 있는 경우 모두 통과
- 1000×560 및 390×540 캔버스에서 내장 그림과 카메라/미니맵 표시
- 한국어 글꼴을 등록한 캔버스로 실제 생물 그림/이름/숲 표시를 시각 확인
- 실제 PNG 출력 1600×1420, 생물/관계선/한국어/학생 생각 표시 확인
- 통합 검사 중 외부 요청 0회

원본 JavaScript와 최종 HTML 안 스크립트 구문 검사 통과.
최종 HTML에는 외부 URL, 외부 스크립트/스타일시트, fetch, WebSocket,
Firebase SDK/API 설정이 없음. 실행할 때 설치나 빌드가 필요 없음.
학급 공동접속용 파일은 수정하지 않음.

검증 한계
실제 갤럭시탭 터치 조작과 브라우저 DOM/CSS 전체 화면 배치는 실기기에서
검사하지 못함. 통합 검사는 DOM 대역/네이티브 캔버스를 사용했고, 캔버스
밖의 HUD와 버튼 배치를 브라우저 화면으로 캡처한 검사가 아님.
실제 기기의 프레임 속도/주사율이나 스피커 출력/기기별 음량을 측정하거나
브라우저에서 소리를 청취한 결과가 아님. 기기별 체감 움직임과 소리는
수업 전에 사용할 기기에서 확인할 수 있음.
