먹이사슬 술래잡기 개인 체험용 1.0.0
검사일: 2026-10-21

자동 검사 12개 통과
- 개인 1명과 컴퓨터 생물 12마리, 종류마다 3마리 생성
- 독립된 두 체험의 상태 분리, 시간/컴퓨터 생물 수 설정
- 일시정지와 재개, 정지 중 시간과 생물 상태 유지
- 라운드별 먹이 미션 기록, 정답 후 다음 역할로 이동
- 네 역할/네 퀴즈/최종 개인 기록까지 완료
- 다시 시작 시 기록 초기화
- 60회/초 시뮬레이션의 3초 숨기 보호 만료
- 계속 방향을 누르지 않아도 나무를 뛰어넘는 점프
- 시작 전과 완료 후 시뮬레이션 정지
- 실행 HTML의 모든 코드와 이미지 내장, 외부 서비스/SDK 호출 부재
- 중복 HTML ID와 필수 조작 요소 확인

완성된 index.html 전체 스크립트를 DOM 대역과 실제 네이티브 캔버스로 실행한
통합 스모크 검사 통과: 시작, 이동, 점프, 잠깐 멈춤/재개, 도움말,
네 역할의 오답/정답/다음 역할, 마지막 기록, 다시 시작.
이 검사에서 외부 요청 0회. 내장 도트 그림을 실제 캔버스로 그리는 것 확인.

모든 원본 JavaScript와 최종 HTML 안 스크립트 구문 검사 통과.
최종 HTML에는 외부 URL, 외부 스크립트/스타일시트, fetch, WebSocket,
Firebase SDK, API 설정이 없음. 실행 시 설치나 빌드가 필요 없음.

개인용은 기존 학급 공동접속용 3.3의 게임 로직/그림/퀴즈를 기반으로 하되,
이동과 컴퓨터 생물을 기기 안에서 초당 60회 계산하고 화면에 직접 표시함.
학급 공동접속용 파일은 수정하지 않음.

한계: 실제 갤럭시탭/학교 Wi-Fi/브라우저별 프레임 속도를 측정한 결과는 아님.
헤드리스 브라우저 다운로드가 완료되지 않아 실제 브라우저 자동화는 실행하지
못했으며, 위 통합 검사는 DOM 대역/네이티브 캔버스를 사용함.
