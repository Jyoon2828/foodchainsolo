# 먹이사슬 술래잡기 — 개인 체험용 1.5

4학년 과학 ‘생물과 환경’에서 동물을 움직이며 먹고 먹히는 관계를 체험하는 웹게임입니다. 이 압축파일을 다른 선생님께 그대로 공유할 수 있습니다. 모든 학생은 각자의 숲에서 혼자 진행하며 Firebase 연결이 필요 없습니다.

## 1.5에서 달라진 점

**화살표 글자 보기 대신 큰 생물 그림으로 퀴즈를 풉니다.** 먹는 동물과 접시 위 먹이 그림을 보고, 빈자리에 들어갈 생물을 고릅니다. 정답을 고르면 두 그림이 함께 나타나 먹이관계를 확인할 수 있습니다. 틀리면 다시 고르며, 정답을 고른 뒤 다음 역할로 진행합니다.

| 마친 역할 | 그림으로 알아볼 관계 |
|---|---|
| 메뚜기 | 메뚜기는 무엇을 먹을까요? — 벼 |
| 개구리 | 개구리는 무엇을 먹을까요? — 메뚜기 |
| 뱀 | 이 놀이에서 개구리를 먹는 동물은? — 뱀 |
| 매 | 이 놀이에서 뱀을 먹는 동물은? — 매 |

문제와 보기에는 화살표 문자열을 사용하지 않습니다. 마지막 정리 화면과 완성한 먹이그물에서는 생물 그림을 연결한 과학 모형을 보여 줍니다.

**먹이그물도 직접 동물을 움직이는 숲 게임으로 바꿨습니다.** 이전 버전의 두 그림을 눌러 연결선을 만드는 활동을 대체합니다. 먹이를 먹거나 천적에게 잡히면 해당 먹이관계가 그림 기록에 쌓입니다.

| 먹이그물 게임 순서 | 모두 찾아 먹을 먹이 |
|---|---|
| 참새 | 벼, 메뚜기 |
| 생쥐 | 벼 |
| 뱀 | 개구리, 생쥐, 참새 |
| 매 | 뱀, 참새 |

각 먹이 종류를 한 번 이상 먹으면 다음 동물로 진행합니다. 이미 먹은 종류는 그림에 체크가 표시됩니다. 시간제한이 없으며, 먹이를 충분히 배치하고 일부는 출발 위치 가까이에 놓았습니다. 잡혀도 찾은 먹이는 유지됩니다. 네 동물의 미션을 모두 마치면 기존 먹이사슬과 합쳐 **7종류 생물·10개 먹이관계**의 그림 먹이그물이 완성됩니다.

게임 중 **먹이 그림 기록**을 누르면 게임을 잠시 멈추고, ‘동물이 먹이를 먹어요’ 형식의 그림 카드로 지금까지 만난 관계를 봅니다. BGM과 먹기·잡힘·빠르게 이동·미션 성공 효과음도 나옵니다.

새 파일을 적용한 뒤 첫 화면에 **‘개인용 1.5 · 그림 퀴즈·먹이그물 게임’**이 보이는지 확인하세요.

## 바로 실행하기와 업데이트

1. 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다. 컴퓨터에서는 더블클릭으로 실행할 수 있습니다.
3. ‘숲속 탐험 시작하기’를 누릅니다. 이미 먹이사슬을 해 본 학생은 **‘먹이그물 활동으로’** 버튼으로 바로 시작할 수 있습니다.

`index.html` 한 파일에 코드·그림·소리가 모두 들어 있습니다. 이 파일만 복사해도 실행되고, 파일을 받은 뒤에는 인터넷 없이 사용할 수 있습니다. 태블릿에서 HTML 파일 열기가 불편하면 배포한 웹주소를 공유하세요.

기존 배포를 바꾸려면 **새 `index.html`로 교체하고 다시 배포한 뒤 새로고침**하세요. 첫 화면의 1.5 표시로 적용 여부를 확인할 수 있습니다. 시작 화면이 예전 버전이면 브라우저를 완전히 닫고 다시 열거나 새로고침해 주세요.

## 링크로 공유하기 — GitHub + Vercel

1. GitHub 저장소에 이 폴더 안의 파일을 올립니다. 최상위에서 `index.html`이 보여야 합니다. 개인용은 학급 공동접속용과 다른 저장소에 올리는 것이 편합니다.
2. Vercel에서 프로젝트로 가져옵니다.
3. Framework Preset은 **Other**, Build Command와 Install Command는 비워 두고, Output Directory는 기본값으로 둡니다. 이미 완성된 정적 HTML이므로 빌드가 필요 없습니다.
4. 배포된 주소를 선생님이나 학생에게 공유합니다.

GitHub Pages 등 일반 정적 호스팅도 가능합니다. Firebase 프로젝트·환경 변수·API 키·로그인이 필요 없습니다. 외부 글꼴·그림·음원도 내려받지 않습니다. 학생들이 같은 주소를 열어도 각자 독립적으로 진행합니다.

## 체험 흐름

1. **먹이사슬 술래잡기:** 메뚜기, 개구리, 뱀, 매의 네 역할을 차례로 맡습니다. 먹이를 찾고 천적을 피하며 역할별 미션에 도전합니다.
2. **그림 퀴즈:** 각 역할이 끝날 때마다 ‘누가 무엇을 먹는지’를 그림으로 고릅니다. 문제 중에는 게임 시간이 흐르지 않습니다.
3. **먹이사슬 정리:** 역할별 기록과 생물 그림으로 연결한 대표 먹이사슬을 봅니다.
4. **먹이그물 숲 게임:** 참새, 생쥐, 뱀, 매로 여러 먹이를 찾습니다. 기존 관계 네 개에서 시작해 새 관계 여섯 개를 더 모읍니다.
5. **변화 살피기:** 완성한 그림에서 개구리를 잠시 가립니다. 뱀에게 남아 있는 생쥐·참새의 관계를 찾고, 두 먹이 그림을 모두 고릅니다. 다른 먹이사슬을 그림으로 골라 강조해 볼 수도 있습니다.
6. **내 생각·저장:** 먹이사슬과 먹이그물의 차이를 그림에서 찾은 근거와 함께 씁니다. 완성한 먹이그물·근거·생각을 **1600×1420 PNG 한 장**으로 저장합니다.

내 생각은 최대 180자이며 자동 채점하지 않습니다. 결과는 학생 기기에 저장되고 교사나 서버로 전송되지 않습니다. 작은 화면에서는 완성한 먹이그물 그림을 옆으로 밀어 살펴볼 수 있습니다.

## 조작

두 게임 모두 왼쪽 조작판, 방향키·WASD, 또는 맵의 빈 곳을 눌러 이동합니다. 먹이에 가까이 가면 자동으로 먹습니다. 오른쪽 행동 버튼이나 스페이스를 사용합니다.

**먹이사슬 술래잡기**

- 메뚜기: 바라보는 방향으로 나무·바위를 훌쩍 뛰어넘기.
- 개구리: 앞쪽으로 혀 뻗기. 뱀: 잠시 숨기. 매: 빠르게 내려오기.
- 메뚜기·개구리·뱀은 나무 가까이나 풀숲에서 멈추면 처음 3초 동안 보호받습니다. 이후에는 숨어 있어도 잡힙니다. 구역 밖에 1초 이상 있어야 다시 보호받습니다.
- 잡히면 2.5초 뒤 재출발하고, 직후 3초 동안 보호받습니다.

**먹이그물 숲 게임**

- 네 동물 모두 ‘빠르게 이동’을 사용할 수 있습니다. 다시 쓰려면 3.5초 기다립니다.
- 노란 테두리의 먹이를 찾습니다. 작은 지도에서 노란 점은 먹이, 초록 점은 나입니다.
- 잡히면 2초 뒤 다시 출발하고, 직후 3초 동안 보호받습니다. 이미 찾은 먹이는 잃지 않습니다.
- 나무는 숲의 가장자리 장식입니다. 이 게임에서는 숨기·점프 대신 여러 먹이 종류를 찾는 데 집중합니다.
- ‘먹이 그림 기록’을 열거나 ‘잠깐 멈춤’을 누르면 진행을 멈춥니다.

도움말·소리 설정을 열면 게임이 멈추고, 닫으면 이전에 진행 중이었던 게임을 이어 갑니다. 다른 탭이나 창으로 이동하면 자동으로 멈춥니다. 돌아와서 ‘계속 탐험하기’를 눌러야 재개됩니다. 처음으로 돌아가기와 새로고침은 기록을 초기화합니다.

## 시간·먹이 수와 부드러운 움직임

먹이사슬 술래잡기의 기본은 **90초 × 네 역할 = 약 6분 + 퀴즈 시간**입니다. ‘체험 시간·숲 친구 바꾸기’에서 60·90·120초와 처음 숲 친구 8·12·16마리를 선택합니다. 먹이그물 게임에는 시간제한이 없습니다.

| 먹이사슬 90초 미션 | 목표 | 보통 설정의 먹이 배치 |
|---|---|---|
| 메뚜기 | 벼 5개 이상 | 벼 24곳, 다시 자람 |
| 개구리 | 메뚜기 3마리 이상 | 메뚜기 8마리 |
| 뱀 | 개구리 2마리 이상 | 개구리 7마리 |
| 매 | 뱀 2마리 이상 | 뱀 6마리 |

시간을 바꾸면 목표도 비례해서 바뀝니다. 역할이 바뀔 때 먹이를 보강하며 중복 누적하지 않습니다. 잡혀도 이번 역할에서 먹은 수를 유지합니다. 미션에 실패해도 모든 역할을 체험할 수 있습니다.

두 게임은 고정 간격으로 위치를 계산하고 그 사이 위치를 이어 그립니다. 과도한 상하 들썩임과 방향 그림의 잦은 뒤집힘을 줄였습니다. 컴퓨터 생물은 방향을 천천히 바꾸며 학생보다 느리게 움직입니다. 먹이그물 게임은 학생을 따라 화면이 움직이고 작은 지도로 전체 위치를 보여 줍니다.

## 소리

시작 버튼을 누르면 기본 음량 35%로 BGM이 시작됩니다. 첫 화면에서는 자동 재생하지 않습니다. 위쪽 **♫ 소리 설정**에서 BGM·효과음을 따로 켜거나 끄고 음량을 0~100%로 조절합니다. ‘효과음 들어보기’도 가능합니다.

음악과 효과음은 브라우저의 Web Audio로 합성합니다. 외부 음원과 추가 다운로드가 없습니다. 일시정지·도움말·소리 설정·그림 기록·다른 탭 이동에서는 게임 소리도 멈춥니다. 퀴즈에는 정답·재도전 효과음이 나옵니다. 오디오를 지원하지 않아도 게임은 진행됩니다. 기기의 음소거와 미디어 음량을 확인하세요.

## 수업 모형과 기록

이 활동에 표시한 대표 먹이관계는 다음과 같습니다.

| 먹히는 생물 | 이 모형에서 먹는 생물 |
|---|---|
| 벼 | 메뚜기, 생쥐, 참새 |
| 메뚜기 | 개구리, 참새 |
| 개구리 | 뱀 |
| 생쥐 | 뱀 |
| 참새 | 뱀, 매 |
| 뱀 | 매 |

자연의 모든 관계를 표시한 것은 아닙니다. 실제 먹이는 생물의 종류·계절·먹이의 양에 따라 달라질 수 있습니다. 학생이 동물 역할을 바꾸는 놀이이며 생물이 다른 종류로 변하는 과정이 아닙니다.

개구리 가리기는 **직접 연결된 관계를 비교하는 학습 모형**입니다. 개체 수나 멸종을 예측하지 않습니다. 한 먹이가 없어져도 남아 있는 먹이관계를 찾아보고, 환경 변화의 영향을 함께 이야기해 보세요.

발문 예: ‘참새로 어떤 먹이를 먹었나요?’, ‘뱀이 먹은 먹이를 모두 찾아볼까요?’, ‘먹기도 하고 먹히기도 한 생물은?’, ‘개구리를 가렸을 때 끊긴 관계와 남은 관계는?’, ‘여러 먹이사슬이 어디에서 만났나요?’

기록과 소리 설정은 현재 열린 페이지 안에서만 유지됩니다. 자동 저장·로그인·이름 입력·서버 전송은 없습니다. 결과가 필요하면 마지막 그림을 저장하거나 화면을 캡처해 제출하도록 안내하세요.

## 코드 수정과 검사

실행 시 설치가 필요 없습니다. 개발용 원본은 `source/`에 있습니다. 수정한 뒤 Python 3으로 `python3 build.py`를 실행하면 완성된 `index.html`을 만듭니다. 검사는 Node로 `node --test tests/*.test.mjs`를 실행하며 별도 npm 설치가 필요 없습니다. 검증 범위와 기기 검사 한계는 `CHECKS.txt`에 적었습니다.

- `source/engine.js`, `source/solo-state.js`: 기존 먹이사슬 게임, 네 역할 진행과 개인 기록.
- `source/quiz.js`, `source/quiz-view.js`: 그림 먹이관계 문제·정답 판정·화면.
- `source/web-hunt.js`: 먹이그물 숲의 이동·추격·먹기·잡힘·네 역할 미션.
- `source/web-hunt-view.js`: 먹이그물 캔버스·카메라·터치·키보드·그림 기록.
- `source/food-web.js`, `source/web-view.js`: 게임 경험을 먹이그물로 모으고 변화 관찰·생각 기록으로 이어가기.
- `source/web-art.js`, `source/web-export.js`: 생물 그림·먹는 관계 카드·PNG 저장.
- `source/audio.js`: 내장 BGM·효과음 합성.
- `source/solo.js`, `source/style.css`, `source/shell.html`: 전체 개인용 진행·화면·소리 설정.
- `source/render.js`, `source/motion-view.js`, `source/assets-inline.json`: 기존 숲·그림·움직임 표시.
- `source/assets/mouse.png`, `source/assets/sparrow.png`: 이 활동용 투명 배경 그림.
- `ASSET_PROMPT.txt`: 그림 제작 안내.
