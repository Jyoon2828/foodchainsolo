## 개인용 1.9.1 · 어디서든 홈으로

- 상단 오른쪽에 **⌂ 홈** 버튼을 항상 표시합니다. 생물 설명·먹이사슬·먹이그물·퀴즈·결과·먹이그물 만들기 화면에서 사용할 수 있습니다.
- 도움말·소리 설정·시간 설정 창에도 상단 홈 버튼이 있습니다.
- 홈으로 돌아가면 열린 안내·만들기·설정 창과 게임을 정리합니다. 진행 중인 게임 기록을 초기화할 때는 기존처럼 확인합니다.
- 직접 만들던 먹이그물의 연결·이름·설명은 홈에 다녀와도 유지됩니다. 새로고침하면 초기화됩니다.

## 개인용 1.9 · 먹이그물 만들기·태블릿 화면

첫 화면에서 같은 크기의 세 버튼으로 활동을 선택합니다.

1. **먹이사슬**: 다섯 생물을 알아보고 메뚜기·개구리·뱀·매를 차례로 체험합니다.
2. **먹이그물**: 열 생물을 알아보고 여덟 동물 중 원하는 동물을 선택합니다.
3. **먹이그물 만들기**: 두 게임에서 만난 관계를 떠올리며, 빈 연결망에 직접 화살표를 만듭니다.

만들기에서는 **먹히는 생물 → 먹는 생물** 순서로 두 그림을 누릅니다. ‘연결 확인’은 이 수업의 대표 모형에 맞는 선을 초록색, 다시 살펴볼 선을 붉은 점선으로 표시합니다. 선 지우기·연결 목록에서 삭제·되돌리기를 지원합니다. 이름과 설명은 선택 입력이며, 학생이 연결한 선만 **1600×1700 PNG**에 저장합니다. 17개 관계를 전부 연결해야 저장되는 방식은 아닙니다.

두 게임의 결과 화면에서 만들기로 이어갈 수 있습니다. 첫 화면에서도 바로 만들 수 있어 교사가 수업 순서를 조절할 수 있습니다. 만들기에서 돌아오면 직전 활동으로 돌아가며, 같은 실행 중에는 만들던 내용이 유지됩니다. 새로고침하면 모든 기록이 초기화됩니다. 서버 저장·로그인·교사 결과 수집은 없습니다.

기존 ‘내 생각 정리하기’는 개구리를 가렸을 때 남은 관계를 근거로 생각을 쓰는 단계였습니다. 이름을 **‘관찰한 내용 쓰기’**로 바꾸고, 개구리를 가린 뒤 생쥐·참새를 찾으면 누를 수 있도록 조건을 안내합니다. 기존 먹이그물과 생각 저장 기능도 유지합니다.

태블릿에서 주요 버튼이 함께 보이도록 첫 화면·생물 설명·동물 선택·그림 퀴즈·결과·관찰·만들기 화면을 정리했습니다. 먹이그물 그림은 화면에 맞춰 축소되어 옆으로 밀 필요가 없습니다. 가로 1024×600·1280×800, 세로 800×1280 브라우저 화면을 확인했습니다. 작은 휴대전화나 키보드를 연 상태에서는 필요한 부분을 스크롤할 수 있습니다. 실제 갤럭시탭의 터치·소리·움직임은 별도 확인이 필요합니다.

압축을 풀고 **index.html**을 열면 인터넷 없이 실행됩니다. GitHub·Vercel 배포에서는 기존 index.html을 이번 파일로 교체하세요. 배포된 주소의 업데이트는 자동으로 이루어지지 않습니다.

# 먹이사슬·먹이그물 탐험 — 개인 체험용 1.6

4학년 과학 ‘생물과 환경’에서 혼자 동물을 움직이며 먹이관계를 체험하는 웹게임입니다. 다른 선생님께 이 압축파일을 그대로 공유할 수 있습니다. Firebase·로그인·서버 연결 없이 각자의 기기에서 실행합니다.

## 1.6에서 달라진 점

참새·생쥐를 기존 메뚜기·개구리·뱀·매와 같은 큰 눈, 굵은 윤곽의 귀여운 도트 그림체로 바꿨습니다. 거미·토끼·토끼풀도 같은 그림체로 추가했습니다. 새 동물은 정면·왼쪽·오른쪽·뒷모습을 사용합니다. 새 그림 원본과 제작 프롬프트는 함께 넣었습니다.

먹이그물 게임도 **먹이사슬과 같은 숲·길·나무·바위·풀숲·연못·이동·특수 동작·숨기·잡힘·재출발·BGM·효과음**을 사용합니다. 이전 1.5의 별도 평지 맵과 고정된 네 동물 순서를 대체합니다.

이제 학생이 **메뚜기·개구리·거미·생쥐·참새·토끼·뱀·매** 중에서 직접 고릅니다. 한 동물의 체험을 정리한 뒤 다른 동물을 자유롭게 다시 고르거나 먹이그물을 살펴볼 수 있습니다. 모든 동물을 정해진 순서로 해야 다음 단계로 넘어가는 방식이 아닙니다.

## 바로 실행하기와 업데이트

1. 압축을 풀고 `index.html`을 브라우저로 엽니다. 컴퓨터에서는 더블클릭으로 실행할 수 있습니다.
2. ‘숲속 탐험 시작하기’로 기존 먹이사슬 네 역할을 시작합니다.
3. 먹이그물부터 하려면 첫 화면의 **‘동물 골라 먹이그물 체험하기’**를 누릅니다.

`index.html` 한 파일에 코드·그림·소리가 모두 들어 있습니다. 파일만 복사해도 실행되고, 받은 뒤에는 인터넷 없이 사용할 수 있습니다. 태블릿에서 HTML 파일 열기가 불편하면 웹주소로 배포하세요.

기존 배포는 새 **`index.html`을 교체해 재배포**하면 됩니다. 교사·학생 브라우저를 새로고침하고 첫 화면의 **‘개인용 1.6 · 동물 선택·같은 숲 먹이그물’** 표시를 확인하세요.

GitHub + Vercel: 폴더 안 파일을 저장소 최상위에 올리고 Framework Preset을 Other로 선택합니다. Build/Install Command는 비우고 Output Directory는 기본값으로 둡니다. 완성된 정적 HTML이므로 설치나 빌드가 필요 없습니다. GitHub Pages 등 일반 정적 호스팅에서도 실행됩니다.

학생들이 같은 주소를 열어도 각자의 숲에서 혼자 진행합니다. 학급 전체가 만나는 공동접속용은 별도 파일입니다. 이 개인용에는 Firebase SDK·API 키·환경 변수·분석 도구가 없으며 그림·글꼴·음악을 외부에서 내려받지 않습니다.

## 먹이그물 체험 순서

1. **동물 선택:** 여덟 동물 그림 중 하나를 고릅니다. 선택한 동물의 먹이는 그림으로, 천적은 이름으로 확인합니다. 벼와 토끼풀은 숲의 생산자이며 조종하는 동물 선택지에 포함하지 않습니다.
2. **시간 선택·출발:** 60·90·120초 중 고릅니다. 기본은 90초입니다. 먹이사슬과 같은 숲에서 먹이를 찾고 천적을 피합니다.
3. **미션·그림 기록:** 먹이를 먹을 때마다 횟수와 종류를 셉니다. 내가 먹거나 잡힌 관계는 ‘먹이 그림 기록’에 쌓입니다. 컴퓨터 동물끼리의 경험을 내 기록으로 세지 않습니다.
4. **체험 정리·그림 퀴즈:** 시간이 끝나거나 위쪽 **‘체험 정리’**를 누르면 현재 기록과 그림 문제를 봅니다. 보기 세 개 중 실제 먹이인 그림은 한 개입니다. 정답 후 ‘다른 동물 고르기’ 또는 ‘나의 먹이그물 살펴보기’를 누릅니다. 미션을 다 채우지 못해도 자신의 기록을 확인하고 계속할 수 있습니다.
5. **먹이그물 살펴보기:** 10종류 생물의 대표 관계 17개를 봅니다. 금색은 직접 만난 관계, 초록은 처음 먹이사슬, 회색은 더 살펴볼 관계입니다. 모든 관계를 직접 경험해야만 그림을 볼 수 있는 것은 아닙니다. 작은 화면에서는 옆으로 밀어 봅니다.
6. **변화와 생각:** 개구리를 잠시 가려 뱀에게 남은 두 먹이를 찾습니다. 그림을 근거로 생각을 쓴 뒤 **1600×1700 PNG 한 장**으로 저장합니다. 결과에서 다른 동물 체험으로 돌아갈 수도 있습니다.

### 90초 먹이그물 미션

먹은 총 횟수와 서로 다른 종류를 함께 셉니다. 먹이가 한 종류인 동물은 그 한 종류만 찾으면 됩니다. 시간을 바꾸면 총 횟수 목표가 비례해서 바뀝니다.

| 고른 동물 | 이 모형의 먹이 | 먹기 횟수 | 서로 다른 종류 |
|---|---|---:|---:|
| 메뚜기 | 벼, 토끼풀 | 5번 | 2종류 |
| 개구리 | 메뚜기, 거미 | 3번 | 2종류 |
| 거미 | 메뚜기 | 3번 | 1종류 |
| 생쥐 | 벼 | 4번 | 1종류 |
| 참새 | 벼, 메뚜기, 거미 | 4번 | 2종류 |
| 토끼 | 토끼풀 | 5번 | 1종류 |
| 뱀 | 개구리, 생쥐, 참새 | 3번 | 2종류 |
| 매 | 뱀, 생쥐, 참새, 토끼 | 3번 | 2종류 |

벼·토끼풀은 각각 24곳에 배치하고 먹은 뒤 다시 자랍니다. 선택한 동물의 먹이를 넉넉히 보강하며 일부는 가까운 위치에 놓습니다. 컴퓨터 생물은 학생보다 느리고 경로를 잠시 유지하며 방향을 천천히 바꿉니다.

## 같은 숲에서의 조작

- 왼쪽 조작판, 방향키·WASD 또는 맵의 빈 곳 누르기로 이동합니다. 나무·바위는 돌아가며, 새는 날아서 통과합니다. 먹이에 가까이 가면 자동으로 먹습니다.
- 행동 버튼 또는 스페이스를 사용합니다. 메뚜기·토끼는 나무·바위를 훌쩍 뛰어넘습니다. 개구리는 혀를 뻗습니다. 생쥐·거미·뱀은 잠시 숨습니다. 참새·매는 빠르게 납니다. 점프·숨기는 수업 놀이를 위한 동작입니다.
- 땅에서 움직이는 동물은 나무·풀숲에서 멈추면 처음 3초 동안 잡히지 않습니다. 이후에는 계속 숨어 있어도 잡힙니다. 구역 밖에 1초 이상 나와야 다시 보호받습니다.
- 잡히면 2.5초 뒤 다시 출발하고 3초 동안 보호받습니다. 먹은 횟수와 찾은 먹이 종류는 유지됩니다.
- 작은 지도는 나의 위치와 현재 동물이 먹을 수 있는 먹이를 보여 줍니다.
- ‘잠깐 멈춤’, 도움말, 소리 설정, 먹이 그림 기록을 열면 게임 시간이 멈춥니다. 닫으면 원래 진행 중이던 게임을 이어 갑니다.
- 다른 탭·창으로 이동하면 자동 정지합니다. 돌아와 ‘계속 탐험하기’를 눌러야 재개됩니다.

## 기존 먹이사슬 체험

메뚜기·개구리·뱀·매의 네 역할을 차례로 맡는 첫 번째 게임은 유지합니다. 기본 90초씩 약 6분에 그림 퀴즈 시간이 더해집니다. 각 역할이 끝나면 큰 생물·먹이 그림에서 답을 고릅니다. 글자로 된 화살표 보기 문제가 아닙니다.

| 90초 먹이사슬 미션 | 목표 | 보통 설정의 먹이 |
|---|---|---|
| 메뚜기 | 벼 5개 이상 | 벼 24곳 |
| 개구리 | 메뚜기 3마리 이상 | 메뚜기 8마리 |
| 뱀 | 개구리 2마리 이상 | 개구리 7마리 |
| 매 | 뱀 2마리 이상 | 뱀 6마리 |

첫 화면에서 시간을 60·90·120초, 처음 숲 친구를 8·12·16마리로 바꿀 수 있습니다. 역할에 맞춰 먹이 동물을 보강하며 중복 누적하지 않습니다. 네 역할의 기록을 본 뒤 동물 선택형 먹이그물로 이어집니다.

## 소리와 기록

사용자가 시작 버튼을 누르면 기본 음량 35%로 잔잔한 BGM이 시작됩니다. ♫에서 BGM·효과음을 따로 켜거나 끄고 음량을 조절합니다. 음악과 효과음은 기기에서 합성하며 외부 음원·유료 서비스·추가 다운로드가 없습니다. 오디오를 지원하지 않는 브라우저에서도 게임을 진행할 수 있습니다.

이름 입력·로그인·서버 전송·자동 영구 저장은 없습니다. 게임 기록과 설정은 열린 페이지 안에서만 유지됩니다. 새로고침하거나 처음으로 돌아가면 초기화됩니다. 결과가 필요하면 마지막 PNG를 저장해 제출하도록 안내하세요. 생각은 최대 180자이며 자동으로 채점하지 않습니다.

## 수업 모형과 참고 자료

이 게임은 여러 종에서 볼 수 있는 대표 먹이관계를 단순화한 수업 모형입니다. 모든 종·계절·성장 단계에 같은 관계가 나타난다는 뜻은 아닙니다. 특히 ‘매’는 맹금류를 대표하는 캐릭터로, 토끼·생쥐를 먹는 관계에는 말똥가리류의 사례도 참고했습니다. 생물 그림의 크기는 실제 크기 비율이 아닙니다.

개구리 가리기는 직접 연결을 비교하는 활동이며, 개체 수 변화나 멸종을 예측하는 시뮬레이션이 아닙니다. 다른 먹이가 남아 있어도 환경 변화의 영향이 없어지는 것은 아닙니다.

확장 관계 참고 자료(2026-10-22 확인, 앱 실행 시 접속하지 않음):

- 국립중앙과학관, [참새](https://www.science.go.kr/mps/scienceSubject/bird/view.do?subjectSid=363): 곤충·벼 이삭·씨앗 등의 먹이.
- Cornell Lab of Ornithology, [Eurasian Tree Sparrow](https://www.allaboutbirds.org/guide/Eurasian_Tree_Sparrow/lifehistory): 참새가 거미를 포함한 절지동물을 먹는 사례.
- Oregon State University Extension, [목초지 무척추동물](https://extension.oregonstate.edu/catalog/pnw-750-invertebrate-pest-management-pacific-northwest-pastures): 메뚜기가 클로버류 잎을 먹는 사례.
- Missouri Department of Conservation, [메뚜기류](https://mdc.mo.gov/discover-nature/field-guide/short-horned-grasshoppers): 거미가 어린 메뚜기와 자란 메뚜기를 잡는 사례.
- Missouri Department of Conservation, [개구리·두꺼비](https://mdc.mo.gov/wildlife/wildlife-facts/amphibian-and-reptile-facts/toad-frog-facts): 개구리의 곤충·작은 거미 먹이.
- U.S. National Park Service, [Eastern Cottontail](https://www.nps.gov/cwdw/learn/nature/eastern-cottontail-rabbit.htm): 토끼가 클로버류를 먹는 사례.
- U.S. National Park Service, [Red-tailed Hawk](https://www.nps.gov/miss/learn/nature/birdsredt.htm): 맹금류가 생쥐·토끼·뱀을 먹는 사례.

## 개발 파일과 검사

실행 시 설치가 필요 없습니다. 개발 원본은 `source/`에 있습니다. 수정 후 `python3 build.py`로 완성된 `index.html`을 만듭니다. Python 표준 라이브러리만 사용합니다. 검사는 `node --test tests/*.test.mjs`로 실행합니다. 검증 범위는 `CHECKS.txt`에 있습니다.

- `source/engine.js`: 두 숲에서 함께 쓰는 이동·경로·장애물·점프·숨기·잡힘. 먹이그물에서는 종별 먹이표를 사용합니다.
- `source/render.js`, `source/motion-view.js`: 같은 숲과 부드러운 표시. 새 동물에는 그림·이름만 지정합니다.
- `source/solo-state.js`, `source/quiz.js`, `source/quiz-view.js`: 기존 네 역할과 그림 퀴즈. 같은 퀴즈 화면을 선택형 먹이그물에서도 사용합니다.
- `source/web-ecosystem.js`: 10종류·17관계·동물 선택 목록·도감 배치.
- `source/web-hunt.js`, `source/food-web.js`: 선택한 동물의 체험·미션·퀴즈·직접 만난 관계·다시 선택·생각 기록.
- `source/web-hunt-view.js`, `source/web-view.js`: 숲 조작·선택 화면·그림 도감.
- `source/web-art.js`, `source/web-asset-frames.js`: 새 동물 네 방향과 토끼풀의 표시 범위.
- `source/assets/web-animals-pixel.png`, `source/assets/clover-pixel.png`: 새 도트 그림 원본. 내장 이미지 생성 도구로 제작했습니다.
- `source/web-export.js`: 1600×1700 결과 PNG 저장.
- `source/audio.js`: 내장 BGM·효과음.
- `ASSET_PROMPT.txt`: 기존·신규 그림 제작 프롬프트와 파일 안내.
